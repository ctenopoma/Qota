# Qota

ローカル専用のタスク管理アプリ。データはすべて手元の JSON ファイルに保存し、ネットワークには接続しない。
Rust + [Slint](https://slint.dev/) で作っている。

## 機能

- 今日 / 受信箱 / 今後（カンバン。カードをドラッグして期日を変えられる）/ カレンダー / プロジェクト別の一覧
- 今日の一覧の並び順を選べる（期日順・優先度順・プロジェクト順・追加順）
- タスク詳細: 優先度・期日・繰り返し・プロジェクト・タグ・メモ・サブタスク（ドラッグで並び替え）
- プロジェクト一覧（未完了のタスクだけを表示。色・名前の編集。列の見出しかサイドバーをドラッグして並び替え、両方の並びは同じ）、タグ
- コマンドパレット (Ctrl+K)、検索 (Ctrl+/)、期限切れ・今日の通知
- Ctrl+C / Ctrl+V でタスクのコピー・貼り付け、Ctrl+Z / Ctrl+Y で操作の取り消し・やり直し、マウスの戻る・進むボタン（Alt+← / Alt+→）で画面の行き来
- ライト / ダーク、JSON のエクスポート / インポート、毎日の自動バックアップ
- ウィンドウを幅 720px 未満（最小 360×420）まで小さくすると mini モードになる（サイドバーが上部バーの「メニュー」から開くドロワーになり、一覧のプロジェクト・タグのバッジを隠し、カレンダーは日ごとの件数だけにする。低いウィンドウではカレンダーがスクロールする）

## ビルド・実行

Rust (stable, MSVC) が必要。

```powershell
cargo run --release
cargo test --release
```

実行ファイルは `target\release\qota.exe`。常駐メモリは約 42 MB（Windows 11、ソフトウェアレンダラ、一覧を表示しただけの状態）。

データは `%APPDATA%\com.example.qota\qota.json`。別の場所を使うときは `QOTA_DATA_DIR` を指定する。同じフォルダに `backups\`（自動バックアップ）、`window.json`（ウィンドウの大きさ）、`ui-state.json`（サイドバーなどの開閉、今日の並び順）、`qota.lock`（二重起動の防止）を置く。

開発用に `QOTA_OPEN=detail|palette|settings|upcoming|calendar|projects|tags|search|notif|confirm|toast` で起動直後にその画面を開ける。`QOTA_STEPS="click:x,y;move:x,y;drag:x1,y1,x2,y2;hold:x1,y1,x2,y2;release:x,y;wheel:x,y,dy;shiftwheel:x,y,dy;type:abc;ctrl:z;alt:left;esc;enter;close"` を付けると、起動 5 秒後から 1 秒おきにその操作をウィンドウへ直接送る（実際のマウス・キーボードは使わない。動作確認用。`hold` は押したまま動かして離さないので、`release` までのドラッグ中の表示を撮れる）。

## 構成

| パス | 中身 |
|---|---|
| `src/models.rs` `store.rs` `seed.rs` `error.rs` | データ型と JSON 永続化、バックアップ |
| `src/commands/` | タスク・サブタスク・プロジェクト・タグ・設定の操作、検索、入出力（ダイアログは `rfd`） |
| `src/view.rs` | 表示用の値づくり、フィルタ・並び替え、oklch→sRGB |
| `src/main.rs` | UI と操作のつなぎ込み |
| `src/history.rs` | 取り消し・やり直し、画面の戻る・進む |
| `src/instance.rs` | 二重起動の防止 |
| `src/window_state.rs` | ウィンドウの大きさ・開閉状態の記憶 |
| `ui/theme.slint` | 色・文字サイズなどのデザイントークン |
| `ui/*.slint` | 画面 |
| `windows/` `assets/` | exe に埋め込むマニフェストとアイコン |

## 動作の決まりごと

- 削除（タスク・サブタスク・プロジェクト・タグ）と完了は確認を出さずに実行し、画面下部のトーストの「元に戻す」で戻せる。確認ダイアログを出すのはデータのリセットと、JSON のインポート（置き換わる件数を見せる）だけ
- Ctrl+Z で 1 つ前の操作を取り消し、Ctrl+Y（Ctrl+Shift+Z）でやり直す。操作の直前のデータを丸ごと最大 20 件積む（`src/history.rs`）。表示モードの切り替えは対象外。トーストには「「abc」の追加を取り消しました」のように何を戻したかを出す
- 入力欄に文字があるときの Ctrl+Z は、入力欄の文字の取り消しになる。入力欄が空のときはアプリの操作の取り消しに回すので、タスクを追加した直後でも Ctrl+Z で追加を取り消せる
- マウスの戻る・進むボタンと Alt+← / Alt+→ で、前に見ていた画面へ移る。詳細パネル・コマンドパレット・検索・通知・日付の一覧が開いているときは、まずそれを閉じる
- 詳細パネルの入力中の内容（タイトル・メモ・サブタスク名）は、Esc・背景クリック・×・別のサブタスクへの移動・ウィンドウの × のどれで閉じても保存する。入力は下書きとして持ち、閉じるときに値が変わったものだけ書く（打鍵ごとに保存すると繰り返しの将来分が作り直されるため）
- 今日ビューで追加したタスクの期日は今日にする
- 今日の並び順は見出しの右のセレクトで選ぶ。期日順は期日の古い順（同じ日はデータの順）、優先度順・プロジェクト順は同じもののあいだを期日順にする。プロジェクト順はサイドバーの並びで、プロジェクトなしは末尾。追加順は追加した時刻の古い順。完了済みも同じ順に並べる。受信箱・プロジェクトの一覧は期日順のまま
- Ctrl+C はマウスが乗っているタスク（なければ開いている詳細のタスク）をコピーし、Ctrl+V で今の画面に貼り付ける。貼り付け先が今日なら期日を今日に、受信箱ならプロジェクトなしに、プロジェクトの画面ならそのプロジェクトにし、ほかの画面ではコピー元と同じにする。完了と繰り返しは引き継がず、サブタスクは未完了に戻す
- タスクをコピーすると OS のクリップボードにタイトルを置くので、ほかのアプリにはタイトルを貼れる。ほかで文字をコピーした後の Ctrl+V ではタスクを貼らない
- 入力欄で文字を選んでいるときの Ctrl+C と、文字が入っている入力欄での Ctrl+V は文字のコピー・貼り付けになる。新規タスクの入力欄が空のときの Ctrl+V はタスクの貼り付けになる
- 繰り返しは、最初の期日から終了日までの分を作成時にまとめて作る（最大 255 件。終了日が空なら繰り返さない）。毎月は最初の日を基準に数え、31 日なら短い月は月末にして次の月は 31 日に戻す
- 繰り返しの 1 件の編集範囲は、詳細パネルの「変更」で「この回だけ」（既定）か「以降すべて」を選ぶ。「以降すべて」は後の未完了の回の題名・メモ・優先度・プロジェクト・タグをその場で書き換え、回ごとの個別のサブタスクなどは消さない。頻度・終了日、「以降すべて」での期日の変更だけは、以降の未完了の回を作り直す
- 期日は詳細パネルの「今日」「明日」「1週間後」でも指定できる。期限切れの期日は 99 日前までは「N日前」と表示する
- 今後（カンバン）のカードは、別の列へドラッグすると期日をその列の最初の日（今日・明日・今週なら明後日、今月なら今週のあとの最初の日、来月なら 1 日など）にする。「記載なし」に落とすと期日を外す。「期限切れ」には移せず、今週・今月に入る日が無いとき（週末・月末）はその旨を出す。繰り返しは、その回だけ動かす。移した直後は「元に戻す」で戻せる。画面の外にある列へは、ドラッグ中に自動で動かないので、先にスクロールしてから落とす
- 初回は今日の一覧の上に、Ctrl+K・Ctrl+/・Ctrl+Z を知らせる 1 行のヒントを出す。「閉じる」を押すと `ui-state.json` の `hint_dismissed` を立てて、二度と出さない（閉じずに終わると次も出る）。開発用フック（`QOTA_OPEN` / `QOTA_STEPS`）のときは出さない
- 二重起動の防止: データフォルダの `qota.lock` を「ほかのプロセスは読むだけ」で開いたままにする。2 つ目の起動はウィンドウを出さずに、既存のウィンドウを前に出して終わる（最小化なら元に戻し、最大化は保つ）。データフォルダ単位なので `QOTA_DATA_DIR` で別のデータを指す起動とはぶつからない
- 自動バックアップ: その日最初の保存の直前に `backups\qota-YYYY-MM-DD.json` を残し、7 日分を保持する。「今日の分があるか」はファイルの有無で判断するので、同じ日に再起動しても朝の分を上書きしない。インポートとリセットの直前には日付に関係なく `qota-…-before-import.json` / `-before-reset.json` を残す。保存は一時ファイルをディスクへ書き出してから置き換える。設定画面の「バックアップから戻す…」はバックアップのフォルダでインポートを開く
- 起動時のウィンドウは作業領域に収めて中央に置き、前回の大きさと最大化を `window.json` に、サイドバーと「完了済み」の開閉・今日の並び順・初回ヒントを閉じたかを `ui-state.json` に残す（qota.json のスキーマは変えない）。起動時の画面はいつも「今日」
- 1 分ごとに日付を確かめ、変わっていれば「今日」と期限切れの表示、日付ピッカーの今日の印を差し替える
- コマンドパレットは IME の変換中は Enter・矢印を横取りしない

## Slint で注意したこと

- 描画はソフトウェアレンダラ。OpenGL (femtovg) だとドライバの分で常駐メモリが約 60 MB 増える
- 日本語表示はシステムフォントへのフォールバックで問題なし。ただし `▶ ⧉ ▸` などの記号は Segoe UI Emoji に落ちて絵文字になる・欠けるので、`Theme.symbol` (Segoe UI Symbol) を明示している
- `Text` には取り消し線・下線が無いので、`Label` で線を重ねて描いている
- `Rectangle` には非推奨の `color` プロパティが残っているので、自作部品の文字色は `text-color`、点の色は `dot-color` と呼ぶ
- 確認ダイアログは rfd の MessageDialog (Win32 MessageBox) だとマニフェスト無しでクラシック表示になるので、アプリ内の `ConfirmDialog` で描く。ファイルダイアログ用に `windows/qota.exe.manifest`（Common Controls v6）とアイコンを exe に埋め込んでいる
- 標準の `DatePickerPopup` は英語表記で「今日」が無いので、日本語の `DatePopup` を自作した
- `backdrop-blur` は無いので、カレンダーの日付の一覧は半透明の背景で覆う
- 折り返し (wrap) の `Text` を ScrollView の中に置くと、開いた直後に一番下までスクロールしてしまうので、設定画面の説明は行を分けて `Label` で出している
- `ScrollView` は縦ホイールで横に動かない（横に動くのは Shift+ホイールと横ホイールだけ）。今後・プロジェクト・タグの横並びの列は、列が縦にスクロールしなかった縦ホイールを `Board` の `TouchArea` で受けて横スクロールに回している。標準のスクロールバーは 2px の線でホバーするまでほぼ見えないので、列が収まらないときだけ自前の横スクロールバーを下に出す
- マウスの戻る・進むボタンは押した位置の部品に届くので、`unstable-winit-030` 機能の `on_winit_window_event` で部品より先に受け取っている。Slint を上げるときはこの API の変更に注意
- ライセンス: Royalty-free ライセンスの条件として設定画面に `AboutSlint` を置いている（配布ページにも Slint のバッジが要る）
